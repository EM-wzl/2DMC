原版合成

右键工作台打开 3×3 合成，随身背包是 2×2。有序配方按 3×3 图案匹配（支持网格内平移），无序配方按材料集合匹配。光标拿取完全按原版：左键拿整堆 / 放整堆 / 同类合并 / 异类交换，右键拿一半 / 放一个。

维度与末影龙

主世界 → 下界：黑曜石门框 + 打火石（或直接 /nether）。末地：主世界地下要塞有末地传送门框架，手持龙蛋右键激活；也可以 /end 直接前往。

末影龙是一条链式 Boss（头部 + 12 节体节 + 尾部，体节沿链跟随），和「世界吞噬者」同一套骨架。行为循环：巡航盘旋 → 俯冲掠过玩家并喷龙息 → 降落到地面栖息（玩家主要输出窗口）。用剑或镐点击龙首近战命中会立刻把它打落。柱顶四枚末影水晶只要还活着，龙栖息时就会持续回血——把它们挖掉才能速战速决。击败后掉落龙蛋并激活退出传送门。

局域网联机（同一浏览器多标签）

标签 A 输入 /lan host，标签 B 输入 /lan join。主机权威，通过 BroadcastChannel 同步完整世界快照、方块变更、玩家位置、维度、末影龙状态与聊天。需要以 http(s) 打开（GitHub Pages 或本地静态服务器），file:// 下浏览器限制跨标签通信。
