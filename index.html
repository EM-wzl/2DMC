生存、天气与音效

HUD 左边是生命，紧挨着的橙色菱形是饱食度。走动、跳跃、挖掘、受伤都会慢慢消耗；饱食度 ≥18 会自然回血，饿空会持续掉血（最低留 1 点）。快捷栏里选中食物后右键吃掉（面包 / 苹果 / 金苹果 / 浆果 / 紫颂果），初始背包带了面包和苹果。

主世界会随机切换晴 / 雨 / 雪 / 雷暴：雪原下雨自动变降雪，沙漠不下雨，下界和末地永远晴朗。雨天天空变暗、光照降低，雷暴有闪电和白闪；地下看不到雨雪。右上角小地图显示周围地形切片、生物（红）、末影水晶（紫）、末影龙、传送门（青）和你自己（白色菱形）。

音效全部由 Web Audio 实时合成，不需要音频文件：脚步、挖掘、破坏、放置、跳跃、受伤、吃食物、拾取、爆炸、龙息、龙吼、传送、雷声和雨/洞穴/下界/末地环境音。浏览器要求首次点击或按键后才出声，按 M 可随时静音。

原版合成

右键工作台打开 3×3 合成，随身背包是 2×2。有序配方按 3×3 图案匹配（支持网格内平移），无序配方按材料集合匹配。光标拿取完全按原版：左键拿整堆 / 放整堆 / 同类合并 / 异类交换，右键拿一半 / 放一个。右侧是配方书：按背包材料列出可做 / 缺材料，可搜索，点「可做」一键把材料摆进合成格。

维度与末影龙

主世界 → 下界：黑曜石门框 + 打火石（或直接 /nether）。末地：主世界地下要塞有末地传送门框架，手持龙蛋右键激活；也可以 /end 直接前往。

末影龙是一条链式 Boss（头部 + 12 节体节 + 尾部，体节沿链跟随），和「世界吞噬者」同一套骨架。行为循环：巡航盘旋 → 俯冲掠过玩家并喷龙息 → 降落到地面栖息（玩家主要输出窗口）。龙息落地后会留下持续伤害的紫色滞留云，别站在里面。用剑或镐点击龙首近战命中会立刻把它打落。柱顶四枚末影水晶只要还活着，龙栖息时就会持续回血——把它们挖掉才能速战速决。击败后掉落龙蛋并激活退出传送门。

局域网联机（同一浏览器多标签）

标签 A 输入 /lan host，标签 B 输入 /lan join。主机权威，通过 BroadcastChannel 同步完整世界快照、方块变更、玩家位置、维度、末影龙状态与聊天。需要以 http(s) 打开（GitHub Pages 或本地静态服务器），file:// 下浏览器限制跨标签通信。

皮肤与生物

玩家小人和僵尸 / 骷髅 / 苦力怕 / 羊 / 僵尸猪灵使用项目内的 MC 皮肤拼成的 2D 正面贴图（beta1.8/assets/skins 与 tools/mob_textures_src）。输入 /skin 查看可用皮肤，/skin alex 切换，选择会记住。蜘蛛、末影人、硫磺方块怪仍是程序化绘制；掉落物也换成真实物品贴图。

贴图资源

方块与物品图标直接使用项目文件夹里的贴图：Default-Java-26.2/assets/minecraft/textures/{block,item}（Minecraft Java 26.2 原版资源包，16×16）为主，beta1.8/assets/tiles（2DMC 自有贴图）补充，共 181 项。动画图集（水/岩浆/下界传送门等）只取第一帧；箱子、末地传送门保留程序化绘制。按 T 可在原版贴图与程序化纹理间切换。
