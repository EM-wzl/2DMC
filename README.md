# 2DMC

2DMC 是一个 Minecraft 式沙盒游戏项目：2025 年 7 月从 Windows 控制台里的一个 2D 小原型起步，历经控制台版（Alpha → Beta 1.x）、OpenGL 图形版（beta1.8 / beta2.0），演进到如今的 3D 体素版 **gamma**（基于开源项目 [OpenMiner](https://github.com/Unarelith/OpenMiner) fork 改造）。

## 版本线一览

| 目录 | 形态 | 说明 |
|------|------|------|
| `classic/` | 2D 控制台 | 2025.7 最初的三个单文件原型（世界数组、挖掘、早期合成） |
| `Alpha/` | 2D 控制台 | Alpha 0.1.8–0.8：光照、实体、昼夜、Boss 等系统逐步成形 |
| `beta/` | 2D 控制台 | beta1.0–2.2 单文件源码存档；**2.2 对标 Minecraft Java 1.0–26.3，含原版 3×3 合成**；详细 Wiki 基于 `beta1.6.cpp` |
| `beta/beta2.1/` | 2D 控制台（模块化） | `beta1.8.cpp` 的原版模块化还原（9 个 `.inc` + `main.cpp`），逐行比对 0 差异，产物 `2DMC21.exe` |
| `beta1.8/` | 2D 图形（OpenGL） | 把 `beta1.8.cpp` 完整重写为贴图渲染，功能全保留，新增耐久度系统、MC 皮肤、矿脉贴图 |

| `video/` `2DMC-launch-video/` `2DMC-remotion-video/` | 视频素材 | 宣传视频成片与 Remotion 工程文件 |

## gamma —— 3D 版（当前主力）

在 OpenMiner（C++17、bgfx + SDL2 渲染）基础上 fork 改造，让 2DMC 走进 3D 体素世界。

**继承自 OpenMiner**：伪无限世界（X/Y/Z 各 2³² 格）、客户端/服务端多人架构、平滑光照 + 环境光遮蔽、昼夜循环、维度系统、Lua 模组 API（方块/物品/配方/生物群系/维度/自定义 GUI）、可带库存的方块（工作台、熔炉）、存档与材质包系统。

**2DMC 本地改造**：

- `gamma/build.bat` 一键编译：自动探测 MinGW-w64 工具链、初始化 git 子模块、编译后自动把客户端部署为 `Minecraft/Minecraft.exe`（附带运行所需 DLL）
- 流体流动系统：水 7 级/岩浆 3 级、失源回退、静置零开销、水+岩浆→黑曜石、桶取放流体；水可冲掉花草继续扩散
- 生物系统：猪/僵尸/羊/蜘蛛/苦力怕/僵尸猪灵，服务端权威游荡 AI + `Event.ServerTick` 自然生成（按真实地表落点、8~24 格环带、数量上限），存档重载后继续活动
- 命令系统：完整移植控制台版 `/help /give /heal /life /kill /gamemode /clear /summon /cheat`，并保留 `/option /stop /time /tp /tps`
- 下界扩展：下界石英矿/岩浆块/玄武岩/黑石/下界疣块/石英块、3 个下界群系、下界专属地形（岩浆湖/玄武岩柱/萤石簇/灵魂沙斑块）
- 玩家生命值与游戏模式（`PlayerHealth`/`PlayerGamemode` 网络包 + HUD 左上 HP 显示）
- 修复中文文本渲染模糊（CJK 字形度量整数量化）
- 修复 Lua 报错导致服务端崩溃（Lua 事件改用 `sol::protected_function`）
- `external/` 第三方库已针对 MinGW-w64 / g++ 打好补丁

### 编译与运行

环境要求：Windows、CMake ≥ 3.12、MinGW-w64 的 g++、Git（首次编译联网拉取子模块）。

```bat
build.bat              :: 仓库根直接运行（自动定位 gamma 文件夹）
:: 或
cd gamma
build.bat
```

编译完成后双击 `Minecraft/Minecraft.exe` 开始游戏；联机先启动同目录的 `openminer_server.exe`。

常用变体：`build.bat Debug`、`build.bat clean`；环境变量 `CMAKE_GEN` / `JOBS` / `DEPLOY_DIR` / `DEPLOY_NAME` 可定制生成器与部署，详见 [gamma/README.md](gamma/README.md)。

## beta2.2 —— 2D 控制台 · Minecraft 1.0–26.3 内容 + 原版合成

`beta/beta2.2.cpp` 以 `beta1.8.cpp` 的完整主世界（Perlin 地形 / 群系 / 洞穴 / 矿井 / 下界 / v3 存档）为基线，把 Minecraft Java 1.0–26.3 的内容铺进 2D 控制台，并把「点列表合成」改成了原版的**网格摆形合成**。

### 原版合成

- **E 键 = 2×2 随身合成**，右键**工作台** = 3×3 合成台（工作台用 4 木板合成，新世界赠送 1 个）
- **原版光标拿取**：左键点物品拿起（物品跟着鼠标走）、再点目标格放下；右键拿走一半 / 放下一个；同类自动合并，异类自动交换；关闭界面时手上的东西自动退回背包
- 配方按**形状**匹配，允许在 3×3 网格内平移；无序配方按材料多重集合匹配
- 左键格子放入 1 个 / 右键取回 1 个；输出槽左键合成一次、右键批量合成
- `R` 打开**配方书**（126 条配方，`,` / `.` 翻页），显示材料数量与产物
- 背包 9×4 + 快捷栏 9 格，左键与手持快捷栏交换；关闭界面时网格材料自动退回背包
- 界面标题写明「原版合成 · 2×2 随身栏 / 3×3 工作台」，`R` 键配方书；`2DMC.exe --selftest-ui` 可打印界面示意图
- 鼠标坐标按**控制台缓冲区格**换算（读取真实字格像素 + 视图滚动量），面板滚动或高 DPI 下都不会点偏
- 提示条改为每帧重绘（持续 4 秒），进入世界会提示 `E` 合成栏 / 右键工作台 3×3 / `R` 配方书 / `M` 地图
- 矿石按原版掉落：铁/金/铜掉粗矿，钻石/青金石/绿宝石掉本体，红石掉 2–4 个

### 末地维度（The End）

第三个维度。维度数据从「两个 20MB 数组物理交换」重构为**指针式三平面**（`dim_terrain[3]` + `s` 指针），切换维度从 O(1000 万格)变成 O(1)。

- **中央岛**：椭圆形末地石台地，表层末地石砖；四根黑曜石柱（高 12–25 格）柱顶各有一枚**末影水晶**

- **外围岛屿链**：1.17+ 风格沿 x 轴延伸的小岛链，带紫颂植物与末地烛
- **虚空**：岛下方是虚空，掉到世界底部持续掉血直至死亡（原版虚空伤害）
- **无昼夜循环**：末地时间静止，天空恒定
- **专属天空**：暗紫黑虚空配色（新增颜色号 -46），末地传送门亮紫（-19）
- **紫颂花**：右键随机传送到末地其他位置（原版机制）
- **末地传送门激活**：放置**末地传送门框架**后用手持**龙蛋**右键激活（原版机制），右键激活后的传送门进入末地
- **新方块/物品**：末地石砖、紫珀柱、紫珀楼梯、紫颂植物、紫颂花、龙蛋、末地传送门、末地传送门框架、末影水晶、黑曜石柱
- **配方**：末地石砖=4 末地石；紫珀柱=2 紫珀块竖排；紫颂植物=紫颂果+末地石；紫颂花=紫颂果+紫颂植物；末地传送门框架=黑曜石+末影珍珠；末影水晶=玻璃+钻石+恶魂之泪；黑曜石柱=黑曜石+末地石

- **命令**：`/end` 直接前往末地（再执行一次回主世界）

### 末影龙（Ender Dragon）

末地的 Boss，**结构完全复用「世界吞噬者」的链式骨架**：`头部(type 15) + 12 节体节(type 16) + 尾部(type 17)`，用 `conl/conr` 串成一条链，头部自主飞行并持有全部血量，体节/尾部沿链跟随（同一套跟随公式），因此和世界吞噬者一样是「一条会动的蛇」。

- **生成**：末地首次生成（`MAP_end`）时自动放出，停在中央岛上空；玩家 `/end` 或走末地传送门进入末地即可看到
- **血量**：160 血（HUD 第 9 行有紫色 `DRAGON` 血条），近战命中龙首扣血
- **行为循环**：`巡航 ST_FLY`（绕中央岛盘旋，间歇喷龙息）→ `俯冲 ST_CHASE`（从玩家身上掠过，接触伤害 6，喷紫色龙息）→ `栖息 ST_ATTACK`（降落在玩家附近地面停留 400 帧，这是主要输出窗口）→ 再起飞
- **被打即降落**：玩家用鼠标点击龙首近战命中，龙会立刻降落栖息，可以反复近战输出（原版机制）
- **末影水晶回血**：柱顶 4 枚末影水晶只要还有存货，栖息期间每 30 帧回 1 血；**把水晶挖掉就不再回血**（原版机制）
- **死亡**：清空整条链 + 爆炸 + **龙蛋掉入背包** + 激活中央岛退出传送门
- **渲染**：头 `D>`、体节 `==`、尾 `T<`（亮紫 -47 / 暗紫 -45），龙息为紫色 `~~`
- **存档**：龙属于末地实体池，随 `TAG_SHITI3` 一起存盘，读档后龙与已破坏的水晶状态都能还原

### 局域网联机（TCP，主机权威）

- 主机：`/lan host [port]`（默认 25565），HUD 显示本机 `IP:端口`
- 加入：`/lan join <ip> [port]`；停止：`/lan stop`；状态：`/lan status`
- 聊天：`/say <消息>`，消息在队友屏幕停留 5 秒
- 主机连接时发送**完整世界快照**（157 个 64 列分块，约 19 MB），随后以 10 Hz 同步玩家位置，方块挖掘/放置即时广播；远程玩家渲染为青色 `{}`
- 协议：`uint32 长度 + uint8 类型 + payload`，类型覆盖 HELLO / WELCOME / WORLD_BEGIN / WORLD_CHUNK / WORLD_END / BLOCK / PLAYER / CHAT
- 限制：只同步方块、玩家位置与聊天；流体、爆炸、生物 AI、容器内容尚未同步；主机需在 Windows 防火墙放行端口

### 世界生成优化

- 热循环改用**内联 xorshift**，避免每格一次 `rand()`
- 湖泊生成改用高度图 `zs[]` 直接定位地表，取消每列向下扫 900 格
- 下界菌柄只遍历真正生成过树的列；深板岩 id 缓存，避免每格 map 查找
- `--bench` 实测：**约 1480 ms → 约 800 ms（-45%）**；阶段：地形 253 / 矿脉 88 / 洞穴 27 / 水岩浆 63 / 下界 313

## beta1.8 / beta2.0 —— 2D 图形版

把控制台版的玩法完整搬到 OpenGL 窗口渲染，仍是纯 MinGW 静态链接、无第三方 DLL 依赖。

- **beta1.8**：在 `beta1.8/` 目录运行 `build.bat` 生成 `2DMC18.exe`（`build.bat console` 保留控制台输出便于调试）。物品/方块贴图放在 `assets/tiles/`，替换同名 PNG 即可换皮、删除自动回退程序化画法；MC 皮肤放进 `assets/skins/`，游戏内 Esc → 设置 → ★ 玩家皮肤 切换。详见 [beta1.8/README.md](beta1.8/README.md)。
- **beta2.0**：在 `beta2.0/` 目录运行 `build.bat` 生成 `2DMC.exe`。源码按 `platform / render / world / entity / game / core` 模块拆分，包含地牢重做与存档链路、战斗数值、实体系统等多阶段修复。
